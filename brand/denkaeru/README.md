# デンカエル ブランド

Claude Design のキャンバス「デンカエル ロゴ・LPデザイン案」から移した内容です。採用したのはロゴA（清書版）です。

## ロゴ

| ファイル | 用途 |
|---|---|
| `symbol.svg` | 標準のシンボル（白・明るい背景） |
| `symbol-on-dark.svg` | 濃い背景用（明るい緑） |
| `symbol-mono.svg` | 1色版（作業着の刺繍・FAX・スタンプ） |
| `icon.svg` | アプリアイコン・LINEアイコン・ファビコン（紺の角丸） |

ロゴタイプ（文字部分）はフォントで組んでいます。「パワコン交換専門店」の帯に続けて「デン」を紺、「カエル」を深緑にし、Zen Kaku Gothic New 900、字間0.04emで組みます。印刷や看板に使うときは、文字をアウトライン化したデータを別途つくってください。
